# About the application
App: electerm
App description: electerm is an open-source terminal / SSH / SFTP / FTP / Telnet / serialport / RDP / VNC / Spice client. Besides the mainstream Windows / macOS / Linux / Android platforms, it also supports HarmonyOS, iOS, and older systems such as Ubuntu 18, Windows 7, macOS 10+, UOS, Kylin, LoongArch (old-world and new-world), RISC-V (riscv64) and ppc64le Linux.
Features: terminal / file manager, SSH / SFTP / FTP / Telnet / serialport / RDP / VNC / Spice client, global hotkey, multi-language support, Zmodem (rz/sz) and Trzsz (trz/tsz), SSH tunnel and global/session proxy, quick commands, UI/terminal themes, gist/WebDAV/cloud sync, AI assistant, MCP widget, deep links, command-line usage
